This project uses primarly HTML, CSS, and JavaScript. The project is about being able to display a panel of different pictures or images and being able to interact with them.
At first, the images just seem to be aligned one next to the other and contain some text in the middle, but clicking them shows an expanded version of the image with the hidden text in it.

Things I learned:
CSS:
I learned a new CSS attribut called "text-transform:" and one of its values, "uppercase". This CSS attribute changes the visual appearence of a selected element (mainly p, and h1-6 elements) but not the HTML source of that element. In this program, the attribute is used to convert the p-elemeents in the panel class to upper case latters. This means that all p-elements in that class will be displayed in capital letter without changing the initial HTML code of the element.

Justify-content, and flex-direction: these two CSS attributes help change the way HTML elements are displayed in the browser. They are both often used together alongside "display: flex" attribute in order to align items in a specific way in the page or in another HTML element.
Flex-direction is used to dictate in which sense (coloum or row mainly) the flex should occur.
In this program, "justify-content" and "flex-direction" are used alongside "display: flex" in order to aligh items in the center of the page and of other HTML elements.
