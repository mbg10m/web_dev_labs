This program is a video player. It uses html for structure, css for styling and javascript for funtionality. The main element used is the <video> element as it enables programmers to display videos in their html.

Things I learned:
I am already familiar with the "input" element and most of its types, but "type='range'" is a new one for me.
This input type doesn't take text or numbers as input but rather uses a range of values, from maximum to minimum, and uses them as input. In this programm, it is used to set the range of volume (min volume(0) and max volume(100)) and also in the video speed (min speed(0.5) and max speed(2)).

Another thing I learned is the "data-skip" property. This property, when used inside a button, allows you to either advance forward or to rewind depending on the value you git it. In this programm, the property is used inside a button along the "video" element, and allows you to go forward (skip) or to rewind the video backwards.
