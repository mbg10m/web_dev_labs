This project is about how to detect mouse movement and create a bunch of shadow effects behing a text.
The HTML and CSS served for structure and styling respectively, and JS for the functionaloty.
In this program, the JS script does a big role in make the shadows exists and making them able to move in different directions. The CSS served mainly in styling those shadows.

Things that I learned:

In this programm, it is hard for my to pint point a single CSS attribute of JS functionality that I learned. Move of the things used in this program are things we have learned in class, apart for the Math related functions.
What I mainly learned, is how to use and eventListener (in this case "mousemove") to interact with an existing HTML element.
I got to learn and understand how to calculate the coordinates at which shadows should appear and provide different colors for every existing shadow. And lastly, how to link the function to an eventListener in order to be able to interact with the HTML text and the created shadows.
